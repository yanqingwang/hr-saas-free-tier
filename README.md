## 说明

| 列 | 含义 |
|---|---|
| 免费版 | 官方公开可用的免费层/免费试用/免费模块（没有就写「无」） |
| 免费情况 | 免费人数上限/模块范围/试用天数 |
| 限制条件 | 哪些功能要付费、人数/数据/导出限制 |
| 何时需升级 | 超过免费人数、需要核心模块、API/SSO 等触发条件 |
| 最小付费包 | 最便宜的付费套餐价格与内容 |
| 官方验证 / 第三方验证 | 链接每周自动探活：✅存活 / 🔒需登录 / 🚫死链 |

## 方法

- 数据源：各厂商**官方定价/免费版页面** + 第三方测评（双源核实优先）；
- 每周一自动探活所有链接并重建表格；「无免费版」的厂商也如实列出，方便对比；
- 免费额度以官网实时口径为准，机器人不替代官网。
